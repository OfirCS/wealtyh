# Design rules

1. One number per screen. One main button per screen.
2. Numbers over sentences. Any line that can be cut gets cut.
3. The app asks, you tap. Never a form when a yes or no will do.
4. Never an empty screen: show what to connect, or a sample.
5. Warm paper, near-black ink, one lime accent `#D6F35B`. Newsreader for headlines, Figtree for everything else, Courier Prime only on receipts.
6. Motion means something happened: spring in, no bounce, under 500ms.
7. A friend must get from landing page to their own number with one button and no explanation.
